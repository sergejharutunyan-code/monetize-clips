# ClipForge — Roadmap

ClipForge turns trends into original animated shorts: research → plot →
Higgsfield → assemble → publish. Legend: `[x]` done · `[~]` partly · `[ ]` planned

## Done

- [x] **Trends**: Claude web research with sources and original angles; Google
      Trends, Wikipedia most-read, YouTube most-popular and evergreen topics;
      a filter for real people, deaths, crime and disasters.
- [x] **Studio**: six formats, house styles, plot packages written by Claude
      (hook, beats, timed scenes, narration sized to length, on-screen text,
      caption, hashtags, fact notes), fully editable; offline template writer.
- [x] **Higgsfield prompts** split to the model's clip length, with the style
      and characters repeated for consistency; character reference prompt;
      prompt pack export.
- [x] **Higgsfield API** generation through the backend, with polling, download
      into storage, retry and cancel.
- [x] **Assemble**: clips in order with trims, teleprompter narration recording
      or uploaded voiceover, burned-in captions and title card in the style's
      caption design, 1080×1920 export with sound.
- [x] **Styles**: five original built-in looks with recurring hosts; editor with
      a warning for studio/franchise names.
- [x] **Publishing** to YouTube, Instagram and TikTok, now or scheduled, or by
      hand via the share sheet.
- [x] Claude from the browser with your own key, so the GitHub Pages site works
      without a backend.

## Next

- [ ] Run against the live Higgsfield and Claude APIs with real keys, and tune
      prompts on real output (style consistency across clips).
- [ ] Character reference images: generate once, then use reference-to-video
      models so the host looks identical in every clip.
- [ ] Text-to-speech narration (one consistent voice without recording).
- [ ] Word-by-word animated captions synced to the narration.
- [ ] Music bed and sound-effect library in Assemble.
- [ ] Real performance analytics from the platforms, fed back into which
      formats and topics to make next.
- [ ] Series: recurring segments with the same host and numbered episodes.
